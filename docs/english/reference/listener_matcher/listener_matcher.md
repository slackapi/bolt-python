## `ListenerMatcher`

### `matches`

```python
matches(req, resp)
```

Matches against the request and returns True if matched.

**Parameters:**

- **req** (BoltRequest) – The request
- **resp** (BoltResponse) – The response

**Returns:**

- bool – True if matched.
