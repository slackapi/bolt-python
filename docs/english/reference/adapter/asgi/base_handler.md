## `BaseSlackRequestHandler`

### `dispatch`

```python
dispatch(request)
```

Dispatches a request to the Bolt App.

### `handle_callback`

```python
handle_callback(request)
```

Handles the callback of the OAuthFlow.

### `handle_installation`

```python
handle_installation(request)
```

Handles installation of the OAuthFlow.
